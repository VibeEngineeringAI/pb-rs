01 / INSTALLTERMINAL

Paste this into your terminal.

curl -fsSL https://github.com/VibeEngineeringAI/pb-rs/releases/download/v0.1.0-rc.1/install.sh | VERSION=0.1.0-rc.1 sh

Detects Apple Silicon or Intel automatically. Installs to ~/.local/bin.

Need to update your PATH?

On macOS or Linux, add this line to your shell configuration (for example, ~/.zshrc or ~/.bashrc), then open a new terminal:

export PATH="$HOME/.local/bin:$PATH"

On Windows, the installer adds its installation directory to your user PATH. Open a new PowerShell window before running pb.

Want a specific version?

Set VERSION to a published release tag, such as v1.2.3 (example only). The installer downloads that release.

curl -fsSL https://github.com/VibeEngineeringAI/pb-rs/releases/download/v1.2.3/install.sh | VERSION=v1.2.3 sh
Prefer to inspect the installer first?

Review the shell installer or PowerShell installer in the repository. Release archives and checksums are available on each release page.
