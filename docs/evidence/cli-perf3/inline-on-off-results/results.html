The main ratio is the median of candidate/baseline (or Rust/Go) round ratios, with observed minimum and maximum. Ratio of medians is supplemental. CPU is the native child CPU total and RSS is native lifetime peak; neither is Python collector usage. Null-sink runs are resource diagnostics admitted only after separate full-output pipe parity. Throughput is withheld unless the source report explicitly admits performance and the sink is a pipe. Write syscall counts, wchar, and charged storage bytes measure different things; none estimates physical SSD wear.

Inputs were explicitly selected. Each report retains its own binary identities; the generator does not infer that different candidate binaries are the same final revision.
