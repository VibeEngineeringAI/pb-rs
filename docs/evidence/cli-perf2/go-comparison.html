Measurement details and downloads

One host, seed 2041, warm local fixtures, stdout through a pipe, CPUs 2/4/6/8. Neither executable was profiled during timing. File placement was controlled because earlier measurements showed placement-dependent RSS. This measures these two builds, not intrinsic language performance or live-server response time. Confidence intervals use 2,000 bootstrap resamples and capture within-run variation, not variation between machines.
