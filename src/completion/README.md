The shell templates are adapted from github.com/spf13/cobra v1.8.1:

- bash.tmpl: bash_completionsV2.go, genBashComp
- fish.tmpl: fish_completions.go, genFishComp
- powershell.tmpl: powershell_completions.go, genPowerShellComp
- zsh.tmpl: zsh_completions.go, genZshComp

Copyright 2013-2023 The Cobra Authors. Licensed under Apache-2.0; the
unmodified license is in LICENSE-Cobra.txt. Templates retain Cobra's indexed
format parameters. The Rust renderer resolves those parameters and percent
escapes; PowerShell's concatenated Go string literals are joined into shell
source. Fish's separately formatted header is emitted by the Rust generator.
The templates are source adapters, not snapshots taken from the Go executable.

`tests/completion.rs` runs the generated adapters through real Zsh ZLE (a Unix
PTY, including actual Tab insertion), Fish `complete --do-complete` (including
escaped filename round trips), and PowerShell `TabExpansion2`. Python 3 drives
bounded subprocesses and kills the process group on Unix timeouts; Windows uses
`taskkill /T`. Each shell runs six cases with descriptions enabled and disabled:
flags, commands, preceding quoted values, Unicode flag values, filenames with
spaces/Unicode/apostrophes, and a trailing empty argument with file completion
disabled. The tests also inspect the protocol argv and description metadata.
PowerShell uses its native engine first, then invokes the registered scriptblock
with a recording function to inspect argv. Zsh's `_describe` recorder delegates
to the real function so the completion engine still performs insertion.

Run `PB_REQUIRE_COMPLETION_SHELLS=1 cargo test --test completion runtime -- --nocapture`
to require every interpreter. A comma-separated list such as
`PB_REQUIRE_COMPLETION_SHELLS=powershell` requires only the named shells. Missing
optional interpreters skip explicitly; invalid explicit runtime paths fail.
`PB_COMPLETION_ZSH`, `PB_COMPLETION_FISH`, and `PB_COMPLETION_POWERSHELL` override
the executable paths. Set `PB_GO_ORACLE` to a built, pinned Go executable to run
the same cases through both generated adapters and compare their observations.
The harness prints runtime versions, case counts, and known inherited failures.
Zsh is tested on Unix; the PowerShell harness also supports native Windows.
For an unpacked Arch Zsh package, `PB_ZSH_LOCAL_ROOT` can supply its module and
completion-function search roots without installing system packages.

These tests preserve two observed Cobra 1.8.1 limitations, reproduced against Go:

- Fish re-evaluates preceding unescaped tokens. For
  `pb sql run --output 'space Ω and "quote"' --h`, the protocol receives
  `--output`, `space`, `Ω`, `and`, `quote`, `--h`, losing the quoted grouping and
  literal double quotes. This is asserted as an inherited limitation, not as
  correct argument preservation.
- On PowerShell 7.4.13, a default directive with no candidates causes the direct
  callback to construct a null `listItemText`; `TabExpansion2` suppresses that
  callback error and successfully performs filename completion. A NoFileComp
  directive with no candidates emits an empty-string sentinel, which can make
  `TabExpansion2` throw a null `completionText` error. The harness records these
  specific errors, rejects unrelated errors, and compares behavior with Go.
  PowerShell versions that accept the empty sentinel must still return no files.

The templates and generated bytes remain unchanged. Fixing these upstream
behaviors would require a separate compatibility decision.
